# Privacy Policy — g-Issue Notifier

Last updated: April 2026

## What we store

- Your Telegram chat ID
- Your GitHub username
- Your GitHub repository subscriptions
- Your label filter preferences
- Your saved response templates

## What we do NOT store

- Your GitHub Personal Access Token in plaintext
- Any message content beyond what is needed to operate the bot
- Any data from GitHub issues beyond what is shown in notifications

## Data location

All data is stored in Cloudflare D1 (SQLite) hosted on Cloudflare's infrastructure.

## Data deletion

Send /unsubscribe to remove all subscriptions.
Contact the bot owner to request full data deletion.
